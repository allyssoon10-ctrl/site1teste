# Priscila Simões | Vida Real nos EUA

Site estático pronto para deploy na Vercel.

## Estrutura
- index.html
- styles.css
- script.js
- assets/foto-familia.jpg

## Publicação na Vercel
1. Extraia este ZIP.
2. Envie o conteúdo da pasta `site-priscila-vercel` para um repositório GitHub.
3. Na Vercel, importe esse repositório.
4. Framework Preset: Other.
5. Build Command: deixe vazio.
6. Output Directory: deixe como `.` (raiz).
7. Clique em Deploy.

A foto principal já está no caminho esperado pelo CSS: `assets/foto-familia.jpg`.
